# What's on near Brandon

A static page of arts, music, theater, talks and nature events near Brandon, Vermont (219 events, 8 Nov to 8 Dec 2026), built 2026-11-08 from the calendar sites listed on the page. No server or build step: publish this folder with GitHub Pages (Settings, Pages, deploy from the main branch, root folder).

Photos and descriptions are read from each event's own page and linked from there (nothing is copied), so they belong to the organizers. Tickets and registration happen on the organizers' sites.
