# What's on near Brandon

A static page of arts, music, theater, talks and nature events near Brandon, Vermont (265 events, 11 Nov to 11 Dec 2026), built 2026-11-11 from the calendar sites listed on the page. No server or build step: publish this folder with GitHub Pages (Settings, Pages, deploy from the main branch, root folder).

Photos and descriptions are read from each event's own page or ticket page (linked, or for the next 60 days a resized copy kept in img/), so they belong to the organizers. Tickets and registration happen on the organizers' sites.
